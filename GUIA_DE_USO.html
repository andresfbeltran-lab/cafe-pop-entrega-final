Volver a Café Pop

Uso y publicación de Café Pop

Abre index.html para recorrer las normas ISO, el caso práctico, los videos y el glosario. Los videos requieren conexión a internet.

Publicar en GitHub Pages

  1. Extrae ambos archivos del ZIP.
  2. Crea un repositorio público y marca Add README.
  3. En la rama main, selecciona Add file → Upload files. Sube index.html y GUIA_DE_USO.html en la raíz y confirma con Commit changes.
  4. Abre Settings → Pages. En Source selecciona Deploy from a branch. Elige main y /(root) y pulsa Save.
  5. Cuando termine la publicación en Actions, abre Settings → Pages → Visit site. Comparte esa dirección.
